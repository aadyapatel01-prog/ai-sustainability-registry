# 🌿 AI Sustainability Registry

An AI-powered platform for tracking, analyzing and registering ESG (Environmental, Social, Governance) sustainability data for organizations.

Built during my internship at **Environmental Management Centre (EMC)** as part of the **SustainPulse** product.

## ✨ Features
- 📊 ESG data registry and tracking
- 🤖 AI agents for sustainability analysis
- 🔐 Authentication with Supabase
- 📱 Responsive Next.js frontend

## 🛠️ Tech Stack
- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** Supabase (PostgreSQL + Auth)
- **AI:** Claude AI agents (AGENTS.md)
- **Deploy:** Vercel
